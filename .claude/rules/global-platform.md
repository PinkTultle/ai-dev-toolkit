# 플랫폼 운용 규칙 (에이전트 · 메모리 · 훅)

> 원본: `blueprints/agent-runtime.md`, `memory-and-context.md`, `hooks.md`
> 검증 버전: Claude Code v2.1.220 — 상세는 원본 blueprint 참조

## 1. 지식 배치 결정

| 성격 | 위치 |
|------|------|
| 매 세션 참인 짧은 사실 | `CLAUDE.md` (200줄 이내) |
| 특정 경로에서만 필요한 지침 | `.claude/rules/*.md` + `paths` frontmatter |
| 여러 단계로 이뤄진 절차 | 스킬 (`SKILL.md`) |
| 반드시 강제해야 하는 규칙 | 훅 또는 `permissions.deny` |
| AI가 스스로 발견한 학습 | auto memory |

CLAUDE.md 항목이 **절차**로 자라면 스킬로, **일부 경로에서만** 의미가 있으면 rule로 옮긴다.

## 2. 서브에이전트

- 서브에이전트는 **기본 백그라운드 실행**이다. 다음 단계의 입력이 되는 산출물은
  **완료를 확인한 뒤** 진행한다. 아직 끝나지 않은 에이전트의 결과를 추측해 보고하지 않는다
- 서로 의존하지 않는 조사·탐색은 병렬로 띄운다
- 서브에이전트는 **이전 단계 산출물 파일만 참조**한다 — 대화 맥락과 부모 세션의 auto memory를
  상속받지 않는다
- 정의 파일의 `name`은 **소문자와 하이픈만** 쓰고 파일명과 일치시킨다
- effort를 올리기 전에 **프롬프트를 먼저 개선한다**. 병목 단계(설계·검토)에만 집중 투자한다
- 상한: 중첩 깊이 3, 동시 20, 세션당 200 — 넘길 규모면 단계를 나눠 순차 실행한다

## 3. Auto memory

- `MEMORY.md`는 **항목당 한 줄인 색인**으로 유지한다 (앞 200줄 또는 25KB만 로드).
  상세는 주제 파일로 내린다
- **저장소가 이미 기록하는 것은 저장하지 않는다** — 코드 구조, 과거 수정 이력, CLAUDE.md 내용
- 상대 날짜는 절대 날짜로 변환해 저장한다
- 메모리는 쓰인 시점의 사실이다. 파일·함수·플래그를 언급하는 메모리는 **사용 전 실재를 확인**한다
- auto memory는 머신 로컬이다 — 다른 워크스테이션과 동기화되지 않는다
- 축적된 내용을 팀 지침으로 올릴 때는 **사용자 합의를 거친다**
  (`communication.md`의 지식 축적 규칙)

## 4. 훅

- 훅은 인자가 아니라 **stdin JSON**을 받는다 — 파일 경로는 `.tool_input.file_path`.
  `$CLAUDE_FILE_PATH` 같은 환경변수는 없다
- 종료 코드: `0` 통과 / `2` 차단(stderr가 AI에 전달) / 그 외 비차단 경고
- 경고성 검사는 반드시 `exit 0` — 개발 흐름을 막지 않는다
- `matcher` + `if`로 대상을 좁히고 `timeout`을 명시한다
- **배포 전에 실제 JSON을 파이프해 검증한다** — 훅은 조용히 실패한다
  ```bash
  echo '{"tool_input":{"file_path":"/tmp/x.md"}}' | bash hook.sh; echo "exit=$?"
  ```
- 런타임이 이미 막는 것(요청하지 않은 파괴적 git 명령, 대상 미지정 `*destroy`)은 중복 구현하지 않는다
